# CyberPi + AI Camera 2.0 ボール追従プログラム（物体認識版）

Makeblock の **CyberPi** と **AI Camera 2.0** を使った、ボール追従プログラムです。
**物体認識**で「学習させた赤ボール／青ボール」だけに反応するので、名前のない色のかたまり（赤い服・青い箱など）には動きません。

## やりたいこと

| 検知したボール | mBot の動き |
| --- | --- |
| 🔴 赤ボール | ボールに向かって追従し、**距離を約10cmに保つ** |
| 🔵 青ボール | ボールから**そっぽを向く**（反対方向へ旋回） |
| なし | その場で停止（ボールを見つけるまで停止のまま待機） |

## 必要なもの

- CyberPi（**mBot2 シャーシ**に載せて走行）
- AI Camera 2.0（mBuild ケーブルで CyberPi に接続）
- 赤・青ボール

---

## 1. 事前準備（AI Camera 2.0 側でボールを学習）

このプログラムは **物体認識** を使います。ボールを**2種類“別々の物体”として**学習させてください。

1. AI Camera 2.0 を **物体認識モード**にする
2. **赤ボール**を学習させ、名前を **`RedBall`** にする（= `RED_BALL`）
3. **青ボール**を学習させ、名前を **`BlueBall`** にする（= `BLUE_BALL`）

学習名は `ball_tracking.py` の `RED_BALL` / `BLUE_BALL` と**必ず一致**させてください（別の名前でもOK。その場合は両方そろえる）。

> ポイント：色ではなく「ボールという物体」を学習するので、ボール以外の赤青には反応しません。

## 2. アップロード手順

1. mBlock で CyberPi を追加 → **Python エディタ**
2. `ball_tracking.py` を貼り付け
3. **アップロードモード**で書き込み

---

## 3. 使っている AI Camera 2.0 の API

| 目的 | 呼び出し |
| --- | --- |
| 物体のX座標を取得 | `mbuild.ai_camera.get_object_x(name, 1)`（**確認済み**。未検出は負の値 -99999） |
| 物体の幅(サイズ)を取得 | `mbuild.ai_camera.get_object_w(name, 1)`（**要確認**。下記参照） |

- 番号 `1` = 一番大きい（＝一番近い）検出
- **mBot2 の前進**は `mbot2.drive_speed(v, -v)`（右モーターは符号反転）

### ⚠ 幅(サイズ)取得 `get_object_w` の確認

距離10cmの維持には、ボールの**見かけの大きさ（幅）**が必要です。`get_object_x` は確認済みですが、`get_object_w` は未確認です。**もしこの行でエラーが出たら**、mBlock で「物体の幅／サイズを取得」ブロックを1つ置き、生成された関数名に `read_ball()` 内の1行を置き換えてください（その名前を教えてもらえれば、こちらで直します）。

## 4. プログラムの動作

```
[起動時]
└─ ボールを見つけるまでは停止して待機（NO BALL 表示）

[ずっと繰り返し]
├─ 赤ボール(RedBall)を読む
│   └─ 検出あり → 追従
│        ・前後: 幅 W を見て、TARGET_WIDTH(=180) より
│                小さい(遠い)→前進 / 大きい(近い)→後退 / 範囲内→停止
│        ・旋回: X が中心(320)からズレている側へ向く
│        ・LED 赤 / 表示 "RED BALL: FOLLOW"
│
├─ 赤なし → 青ボール(BlueBall)を読む
│   └─ 検出あり → そっぽを向く
│        ・ボールと反対方向へその場旋回 / LED 青 / 表示 "BLUE BALL: TURN AWAY"
│
└─ どちらも無し → 停止 / LED消灯 / "NO BALL"
```

## 5. キャリブレーション（実機合わせ）

`ball_tracking.py` 上部の定数を調整します。

| 定数 | 意味 | 合わせ方 |
| --- | --- | --- |
| `RED_BALL` / `BLUE_BALL` | 学習させたボールの名前 | AI Camera の学習名と一致させる |
| `TARGET_WIDTH` | 約10cmのときの幅(px) | 赤ボールを**実際に10cm前**に置き、そのときの幅を測って設定（初期値180） |
| `WIDTH_TOLERANCE` | 距離OKとみなす幅の幅 | 大きくすると前後の揺れ（ハンチング）が減る |
| `FRAME_CENTER_X` | 画面中心X | 実機のXの範囲を見て決める（色認識では320だった） |
| `X_TOLERANCE` | 中央とみなす左右の許容差 | 大きくすると中央付近のふらつきが減る |
| `KP_DRIVE` | 距離ずれ→前後速度の係数 | 小さくすると穏やか |
| `KP_TURN` | 左右ずれ→旋回の係数 | 追従の曲がりが鈍ければ大きく、ふらつけば小さく |
| `MAX_SPEED` | 前後速度の上限 | 速すぎて乱れるなら下げる |
| `SPIN_SPEED` | 青のとき背を向ける旋回速度 | — |
| `LOOP_INTERVAL` | 制御周期（秒） | 反応を速くしたいなら小さく |

### 距離10cmの考え方

AI Camera 2.0 は距離を cm で直接は返さないため、**ボールの見かけの幅（ピクセル）を距離の代わり**に使います。近いほど幅が大きくなります。`TARGET_WIDTH` を「10cm のときの幅」に設定し、それより小さければ前進、大きければ後退して約10cm を保ちます。**まず実測で `TARGET_WIDTH` を決める**のが最重要です。

---

## 調整のコツ

- ボールがふらついて止まらない → `WIDTH_TOLERANCE` / `X_TOLERANCE` を大きく、`KP_DRIVE` を小さく
- 反応が鈍い → `KP_TURN` / `KP_DRIVE` を大きく、`LOOP_INTERVAL` を小さく
- ボール以外に反応する → 学習データを撮り直す（いろいろな角度・明るさでボールを学習）
- 赤と青の反応が逆 → `RED_BALL` と `BLUE_BALL` の名前を入れ替える
