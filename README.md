# CyberPi + AI Camera 2.0 ボール追従プログラム

Makeblock の **CyberPi** と **AI Camera 2.0** を使った、色付きボールの追従プログラムです。

## やりたいこと

| 検知したボール | mBot の動き |
| --- | --- |
| 🔴 赤 | ボールに向かって追従し、**距離を約10cmに保つ** |
| 🔵 青 | ボールから**そっぽを向く**（反対方向へ旋回） |
| なし | その場で停止 |

## 必要なもの

- CyberPi（**mBot2 シャーシ**に載せて走行させます。エンコーダモーターで前後・旋回します）
- AI Camera 2.0（mBuild ケーブルで CyberPi に接続）
- 付属の赤・青ボール

---

## 1. Python 版（mBlock Python エディタ）

`ball_tracking.py` をそのまま使えます。

1. mBlock を開き、デバイスに **CyberPi** を追加
2. **Python エディタ**に切り替え
3. `ball_tracking.py` の内容を貼り付け
4. **アップロードモード**で CyberPi に書き込み

### 事前準備（AI Camera 2.0 側で色を学習）

このプログラムは AI Camera 2.0 の **色認識** を使います。先に実機側で色を2つ学習させてください。

1. AI Camera 2.0 を **色認識(Blob)モード**にする
2. 赤ボールを学習させ、名前を **`red`** にする
3. 青ボールを学習させ、名前を **`blue`** にする

学習名は `ball_tracking.py` の `RED_NAME` / `BLUE_NAME` と**必ず一致**させてください。

### ⚠ カメラ取得関数の確認（1か所だけ）

確認済みの API は `mbuild.ai_camera.get_object_x('名前', 1)` で、**未検出のとき `-99999`** を返します（番号 1 = 一番大きい＝一番近い検出）。AI Camera 2.0 は**学習ラベル名（物体名でも色名でも）を `get_object_*` で読む統一API**と考えられるため、色を `red` / `blue` の名前で学習し、`get_object_*` で読みます。

| 取得したい値 | コード内の呼び出し |
| --- | --- |
| X 座標 | `mbuild.ai_camera.get_object_x(name, 1)` |
| Y 座標 | `mbuild.ai_camera.get_object_y(name, 1)` |
| 幅 W | `mbuild.ai_camera.get_object_w(name, 1)` |
| 高さ H | `mbuild.ai_camera.get_object_h(name, 1)` |

**もし `get_object_w` / `get_object_h` でエラーが出たら**、その2つだけ実機の「幅／高さを取得」ブロックが生成する関数名に置き換えてください（X 座標 `get_object_x` は確認済み）。

## 2. ブロックプログラム版（mBlock）

Python を使わずブロックで組む場合の流れです。

```
[CyberPi が起動したとき]
└─ AI Camera 2.0：色認識(Blob)を開始する

[ずっと]
├─ もし〈Blob の数 > 0〉なら
│   ├─ 変数 色  ← 一番大きい Blob の色
│   ├─ 変数 X   ← その Blob の X
│   ├─ 変数 W   ← その Blob の 幅
│   │
│   ├─ もし〈色 = 赤〉なら
│   │   ├─ LED を赤に
│   │   ├─ 旋回量  = 0.25 ×（X − 160）            ← 中央に合わせる
│   │   ├─ 前後速度 = 0.6 ×（80 − W）             ← 10cmを保つ
│   │   │      ・W が小さい(遠い) → 前進
│   │   │      ・W が大きい(近い) → 後退
│   │   │      ・80±10 の範囲なら 0（停止）
│   │   ├─ 左モーター速度 = 前後速度 + 旋回量
│   │   └─ 右モーター速度 = 前後速度 − 旋回量
│   │
│   ├─ でなければ もし〈色 = 青〉なら
│   │   ├─ LED を青に
│   │   └─ ボールと反対方向にその場で旋回（背を向ける）
│   │        ・X ≧ 160（右）→ 左回転
│   │        ・X <  160（左）→ 右回転
│   │
│   └─ でなければ 停止
│
└─ でなければ（ボールなし）
    ├─ LED 消灯
    └─ 停止
```

「一番大きい Blob」は、各 Blob の `幅 × 高さ` が最大のものを選びます（一番近いボール）。

## 3. キャリブレーション（実機合わせ）

`ball_tracking.py` の上部にある定数を、実機に合わせて調整してください。

| 定数 | 意味 | 合わせ方 |
| --- | --- | --- |
| `FRAME_CENTER_X` | カメラ画面の中心 X | 解像度が 320×240 なら 160。実機の X 座標系に合わせる |
| `TARGET_WIDTH` | 10cm のときのボールの幅(px) | 赤ボールを **実際に10cm前**に置き、画面に出る W の値を読んで設定 |
| `WIDTH_TOLERANCE` | 「ちょうど良い」とみなす幅の許容差 | 大きくすると前後の揺れ（ハンチング）が減る |
| `KP_TURN` | 左右ずれ→旋回の強さ | ボールを追う向きが鈍ければ大きく、ふらつけば小さく |
| `KP_DRIVE` | 距離ずれ→前後の強さ | 近づき方が遅ければ大きく、行き過ぎれば小さく |
| `MAX_SPEED` | 速度上限 | 速すぎて制御が乱れるなら下げる |

### 距離10cmの考え方

AI Camera 2.0 は距離を cm で直接は返さないため、**ボールの見かけの幅 W（ピクセル）を距離の代わり**に使います。近いほど W は大きくなります。`TARGET_WIDTH` を「10cm のときの W」に設定し、それより小さければ前進、大きければ後退することで約10cm を保ちます。まずは実測で `TARGET_WIDTH` を決めるのが重要です。

---

## 調整のコツ

- ボールがふらついて止まらない → `WIDTH_TOLERANCE` を大きく、`KP_DRIVE`/`KP_TURN` を小さく
- 反応が鈍い → ゲインを大きく、`LOOP_INTERVAL` を小さく
- ノイズで誤検知する → `MIN_BLOB_WIDTH` を大きく
- 色の認識精度が低い → AI Camera 2.0 側で赤・青の色を学習し直す（明るい環境で）
