# CyberPi + AI Camera 2.0 ボール追従プログラム

Makeblock の **CyberPi** と **AI Camera 2.0** を使った、色付きボールの追従プログラムです。

## やりたいこと

| 検知したボール | mBot の動き |
| --- | --- |
| 🔴 赤 | ボールに向かって追従し、**距離を約10cmに保つ** |
| 🔵 青 | ボールから**そっぽを向く**（反対方向へ旋回） |
| なし | その場で停止 |

## 必要なもの

- CyberPi（**mBot2 シャーシ**に載せて走行させます。エンコーダモーターで前後・旋回します）
- AI Camera 2.0（mBuild ケーブルで CyberPi に接続）
- 付属の赤・青ボール

---

## 1. 事前準備（AI Camera 2.0 側で色を学習）

このプログラムは AI Camera 2.0 の **色認識（Blob）** を使います。先に実機側で**色を2つ**、この順番で学習させてください。

1. **1色目** … 赤ボールを学習（= 色番号 **1** → `RED_INDEX`）
2. **2色目** … 青ボールを学習（= 色番号 **2** → `BLUE_INDEX`）

学習させた順番と `ball_tracking.py` の `RED_INDEX` / `BLUE_INDEX` を一致させてください（順番が逆なら番号を入れ替える）。

> 色認識モードへの切り替えはプログラム側（`start_color_recognition()`）で自動的に行います。

## 2. アップロード手順

1. mBlock を開き、デバイスに **CyberPi** を追加
2. **Python エディタ**に切り替え
3. `ball_tracking.py` の内容を貼り付け
4. **アップロードモード**で CyberPi に書き込み

---

## 3. 使っている AI Camera 2.0 の API（動作確認済み）

| 目的 | 呼び出し |
| --- | --- |
| 色認識モードに切り替え | `mbuild.ai_camera.ai_camera_set_func_switch(3, 1)` |
| 現在のモードを取得 | `mbuild.ai_camera.ai_camera_func_mode_get(1)`（`'Color'` になればOK） |
| 値の取得 | `mbuild.ai_camera.ai_camera_color_spatial_attribute_get(色番号, 属性, 検出番号)` |

- **属性**：`1` = X座標、`3` = 幅(W)
- **未検出**のときは**負の値（< 0）**が返る
- **座標系**：画面幅 640 → **中心 X = 320**
- **mBot2 の前進**は `mbot2.drive_speed(v, -v)`（右モーターは符号反転）

---

## 4. プログラムの動作

```
[起動時]
└─ 色認識モードになるまで待つ（start_color_recognition）

[ずっと繰り返し]
├─ 赤(色番号1)を読む
│   └─ 検出あり → 追従
│        ・前後: 幅 W を見て、TARGET_WIDTH(=180) より
│                小さい(遠い)→前進 / 大きい(近い)→後退 / 範囲内→停止
│        ・旋回: X が中心(320)からズレている側へ向く
│        ・LED: 正面=緑 / 右にボール=右側黄 / 左にボール=左側黄
│
├─ 赤なし → 青(色番号2)を読む
│   └─ 検出あり → そっぽを向く
│        ・ボールと反対方向へその場旋回 / LED=青
│
└─ どちらも無し → 停止 / LED消灯
```

## 5. キャリブレーション（実機合わせ）

`ball_tracking.py` 上部の定数を調整します。

| 定数 | 意味 | 合わせ方 |
| --- | --- | --- |
| `RED_INDEX` / `BLUE_INDEX` | 学習した色の番号 | 学習した順番に合わせる |
| `TARGET_WIDTH` | 約10cmのときの幅(px) | 赤ボールを**実際に10cm前**に置き、そのときの幅を測って設定（初期値180） |
| `WIDTH_TOLERANCE` | 距離OKとみなす幅の幅 | 大きくすると前後の揺れ（ハンチング）が減る |
| `CENTER_X` | 画面中心X | 通常 320（画面幅640） |
| `DRIVE_DIV` | 距離→前後速度の係数 | 小さいほど機敏（行き過ぎるなら大きく） |
| `TURN_K` / `TURN_DIV` | 左右ズレ→旋回 | 追従の曲がりが鈍ければ `TURN_K` を大きく |
| `MAX_SPEED` | 前後速度の上限 | 速すぎて乱れるなら下げる |
| `SPIN_SPEED` | 青のとき背を向ける旋回速度 | — |

### 距離10cmの考え方

AI Camera 2.0 は距離を cm で直接は返さないため、**ボールの見かけの幅 W（ピクセル）を距離の代わり**に使います。近いほど W は大きくなります。`TARGET_WIDTH` を「10cm のときの W」に設定し、それより小さければ前進、大きければ後退して約10cm を保ちます。**まず実測で `TARGET_WIDTH` を決める**のが最重要です。

---

## 調整のコツ

- ボールがふらついて止まらない → `WIDTH_TOLERANCE` を大きく、`DRIVE_DIV` を大きく
- 反応が鈍い → `TURN_K` を大きく、`DRIVE_DIV` を小さく
- 色の認識精度が低い → AI Camera 2.0 側で赤・青を**明るい環境で**学習し直す
- 赤と青の反応が逆 → `RED_INDEX` と `BLUE_INDEX` を入れ替える
